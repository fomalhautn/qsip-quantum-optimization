01 / Introduction

What is optimization?

Optimization means choosing the best solution according to an objective—such as minimizing travel distance, cost or time—while satisfying any rules.

Three parts of the problem

Decision variablesWhat can change? Here, which route to take.
ObjectiveWhat is best? Here, the smallest total distance.
ConstraintsWhat rules apply? Here, reach the destination and visit required stops.

The same ideas apply to finance, transport, scientific computing and network analysis.

Why can optimization become hard?

For n yes/no decisions, there are 2n assignments. Each new decision doubles the number of possibilities.

1,024
possible assignments

2¹⁰ = 1,024

This is the number of possible answers—not the number of steps every algorithm must perform. Classical optimizers can exploit structure rather than testing everything.

02 / Methods

Why quantum?

Hard combinatorial problems motivate researchers to test new methods. Quantum circuits offer a different way to prepare and sample candidate solutions. That does not guarantee a speedup over classical methods.

A classical solver can check every answer for a small problem or use heuristics for larger ones. QAOA is a hybrid quantum–classical algorithm. Its quantum circuit has adjustable settings; a classical optimizer chooses those settings to improve the average solution score.

2 / FORMULATION

QUBO / Ising

QUBO writes the score using 0/1 choices and terms involving at most two choices. Ising writes the same problem using −1/+1 variables so it can be expressed as a quantum cost operator. Neither is a solving algorithm.

3 / ALGORITHM

QAOA

Build a quantum circuit with adjustable angles, sample possible answers, and let a classical optimizer change the angles to improve the average score.

Four terms worth understanding

Bit and qubit
A bit is 0 or 1. A qubit can be in a superposition before measurement; a measurement returns an ordinary 0 or 1.
Cost Hamiltonian
A quantum operator that encodes the optimization objective. For each candidate bitstring, its eigenvalue represents the solution score (or its negative, depending on the formulation). QAOA uses this operator to apply score-dependent phases.
Tunable angles
γ (gamma) controls the cost operation; β (beta) controls the mixer operation. A classical optimizer repeatedly changes these values. “Tunable” just means adjustable.
Shot and score
One shot measures the circuit once and returns one bitstring (a candidate answer). We calculate its score. The average over many shots tells us how reliably the circuit generates good answers.

What QAOA actually does: Start with qubits, apply a cost operation and a mixer, measure candidate answers, then update γ and β classically. Repeat in the simulator to improve the expected score. This does not read out every answer simultaneously.

Why test it? QAOA may generate useful solution distributions for some problems, but realistic performance must be benchmarked against strong classical algorithms. Finding an optimal answer in a small example is not quantum advantage.
